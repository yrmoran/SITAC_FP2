# SITAC - Sistema de Gestión de Incidencias de Atención al Cliente

Proyecto para IS275 Fundamentos de Programación 2.

## Funcionalidades
Registro, búsqueda, listado, priorización, asignación, actualización de estado y estadísticas.

## POO
Incluye clases, relaciones, herencia, polimorfismo, clases abstractas, listas, excepciones y patrón Singleton.

## Ejecución
`python main.py`

## Pruebas
`python -m unittest discover -s tests -v`

## Demostración sugerida
Cargar datos demo → listar → priorizar → buscar → asignar → actualizar → estadísticas → registrar ticket → probar ticket inexistente.
